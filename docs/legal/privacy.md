# 개인정보처리방침

**시행일자: {{TODO: YYYY-MM-DD}}**
**최종 수정일: {{TODO: YYYY-MM-DD}}**

링링(이하 "회사")은 「개인정보 보호법」 제30조에 따라 정보주체의 개인정보를 보호하고 이와 관련한 고충을 신속하게 처리할 수 있도록 다음과 같이 개인정보처리방침을 수립·공개합니다.

> 본 문서는 초안입니다. 회사 법적 정보(상호·주소·대표자·사업자등록번호), 보유 기간 정책, 위탁 업체 명단, 개인정보 보호책임자 정보 확정 후 변호사 검토를 거쳐 시행해야 합니다.

---

## 제1조 (개인정보의 처리 목적)

회사는 다음의 목적을 위하여 개인정보를 처리합니다. 처리한 개인정보는 다음 목적 외의 용도로는 이용되지 않으며, 이용 목적이 변경될 시에는 사전 동의를 구할 예정입니다.

1. **회원 가입 및 관리** — 회원 식별, 본인 확인, 부정이용 방지, 만 14세 미만 가입 제한 확인
2. **서비스 제공** — 1:1 음성 통화 매칭, 통화 기능 제공, 학습 통계(레벨·매너온도·연속 학습일) 산출
3. **AI 학습 피드백 생성** — 통화 음성 분석 및 영어 표현 추천
4. **민원 처리 및 분쟁 해결** — 신고·차단 접수, 고객 문의 응대
5. **법령상 의무 이행** — 정보통신망법·전자상거래법·청소년보호법 등에 따른 의무 이행

## 제2조 (처리하는 개인정보의 항목)

회사는 다음의 개인정보 항목을 처리하고 있습니다.

### 1. 회원 가입 시 (필수)

| 구분 | 항목 | 출처 |
|---|---|---|
| 소셜 로그인 식별자 | 카카오 또는 Apple의 고유 ID(`sub`) | OAuth 인증 |
| 닉네임 | 자동 생성된 표시 이름 | 회사 자동 생성 |
| 인증 토큰 | 자체 발급 Access Token, Refresh Token | 회사 발급 |
| 생년월일 | 가입 시 입력 (만 14세 미만 차단·청소년 보호용) | 사용자 입력 |

### 2. 서비스 이용 과정에서 자동 수집

| 구분 | 항목 |
|---|---|
| 통화 음성 데이터 | 1:1 음성 통화 중 캡처되는 사용자 음성 |
| 통화 기록 | 통화 시각, 통화 시간, 매칭 상대 ID |
| 학습 통계 | 레벨, 매너온도, 누적 통화 수, 학습한 표현 수 |
| 신고 내역 | 신고 카테고리, 신고 사유 자유서술 |
| 차단 기록 | 차단한 사용자 ID 목록 |
| 네트워크 정보 | IP 주소, WebRTC ICE 후보 (P2P 연결 수립용) |
| 기기 정보 | OS, 앱 버전, 단말 모델 식별자(소셜 SDK가 수집하는 범위) |

### 3. Apple로 로그인 사용 시 (선택)

| 구분 | 항목 |
|---|---|
| 이메일 주소 | Apple ID에 등록된 이메일 또는 비공개 릴레이 주소 (사용자가 공유 선택 시) |
| 이름 | 사용자가 가입 시 공유 선택한 경우에 한함 |

> Apple은 위 항목을 **최초 1회 인증**에서만 회사에 전달합니다. 사용자는 Apple ID 설정에서 언제든 이메일 공유를 중단할 수 있습니다.

## 제6조 (정보주체의 권리·의무 및 행사방법)

1. 정보주체는 회사에 대해 언제든지 다음 각 호의 권리를 행사할 수 있습니다.
   - 개인정보 열람 요구
   - 오류 등이 있을 경우 정정 요구
   - 삭제 요구
   - 처리정지 요구
2. 권리 행사는 회사에 대해 서면, 이메일, 앱 내 문의하기를 통해 하실 수 있으며 회사는 이에 대해 지체 없이 조치합니다.
3. 회원 탈퇴(앱 내 "탈퇴하기" 메뉴)를 통해 회원 정보의 즉시 파기를 요청할 수 있습니다.

## 제7조 (개인정보의 파기)

1. 회사는 개인정보 보유기간의 경과, 처리목적 달성 등 개인정보가 불필요하게 되었을 때에는 지체 없이 해당 개인정보를 파기합니다.
2. 파기 절차 및 방법은 다음과 같습니다.
   - **전자적 파일**: 복구 불가능한 방법으로 영구 삭제
   - **종이 문서**: 분쇄기로 분쇄하거나 소각

## 제8조 (개인정보의 안전성 확보 조치)

회사는 다음과 같은 조치를 취하고 있습니다.

1. **관리적 조치** — 내부관리계획 수립·시행, 정기적 직원 교육
2. **기술적 조치** — 접근 권한 관리, 접근 통제 시스템 설치, 고유 식별정보 등의 암호화, 보안 프로그램 설치
3. **물리적 조치** — 전산실, 자료보관실 등의 접근 통제

## 제9조 (만 14세 미만 아동의 개인정보 보호)

1. 회사는 본 서비스가 만 14세 이상의 사용자를 대상으로 함을 명시하며, 가입 시 생년월일을 입력받아 만 14세 미만의 가입을 제한합니다.
2. 만 14세 미만으로 확인된 경우 가입이 차단되며, 사후 발견 시 즉시 계정을 정지하고 관련 정보를 파기합니다.

## 제10조 (개인정보 자동 수집 장치의 설치·운영 및 거부에 관한 사항)

본 앱은 별도의 쿠키를 사용하지 않으며, 인증 토큰을 단말 내 보안 저장소에 저장합니다. 사용자는 OS의 앱 데이터 삭제 기능 또는 본 앱의 로그아웃·탈퇴 기능을 통해 저장된 토큰을 제거할 수 있습니다.
