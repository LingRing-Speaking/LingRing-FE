# Google Play 데이터 보안(Data Safety) 양식 매핑

Play Console > 앱 콘텐츠 > **데이터 보안(Data Safety)** 양식 작성을 위한 단일 참조 문서.
iOS `Privacy Manifest`(`ios/App/App/PrivacyInfo.xcprivacy`)와 실제 클라이언트 데이터 흐름을 근거로 작성한다.
양식 제출은 Play Console(웹)에서 수동으로 하며, **이 문서가 그 답변의 정본**이다.

> 작성 원칙: 앱이 **실제로** 수집·전송하는 것만 선언한다. 미설치 기능(푸시·Sentry 등)은 선언하지 않고, 도입 시 이 문서와 양식을 함께 갱신한다.

## 1. 전제 — 수집 데이터의 출처

| 데이터 | 출처(코드) | 비고 |
|---|---|---|
| 사용자 식별자 | 카카오/애플 소셜 로그인 → BE 계정 발급 | 닉네임은 **서버 랜덤 발급**. 애플 email/name 은 **BE 미전송** (수집 안 함) |
| 프로필 사진 | 프로필 이미지 업로드 (상한 30MB) | **선택** 입력 |
| 통화 음성 녹음 | 통화 녹음 → 분석 요청 시 업로드 (#158~#161) | **선택** (통화+분석 사용 시에만) |
| 앱 사용 활동 | 통화 기록·학습 통계·분석 결과 | 앱 기능 제공용 |
| 인증 토큰 | 로컬 저장(`@capacitor/preferences`) + BE 통신 | 계정 자격 증명 — 별도 공개 항목 아님 |

현재 **미설치**(선언 제외): 푸시 토큰(FCM), 분석/광고 SDK, 크래시 리포팅(Sentry). → 도입 시 갱신.

## 2. Data Safety — 수집 항목 답변

모든 항목 공통: **추적(Tracking) 없음**, **제3자 광고 목적 없음** (iOS `NSPrivacyTracking=false`).
"수집됨 / 사용자에 연결됨(Linked) / 일시적이지 않음 / 제3자 공유는 §3 참조".

| Play 카테고리 → 데이터 유형 | 수집 | 필수/선택 | 목적 |
|---|---|---|---|
| 개인 정보 → **사용자 ID** | 예 | 필수 | 앱 기능, 계정 관리 |
| 사진 및 동영상 → **사진** | 예 | 선택 | 앱 기능 |
| 오디오 → **음성 또는 사운드 녹음** | 예 | 선택 | 앱 기능 |
| 앱 활동 → **앱 상호작용** | 예 | 필수 | 앱 기능 |

선언하지 **않는** 항목(앱이 수집 안 함): 위치, 금융, 건강·피트니스, 연락처, 메시지, 캘린더, 웹 검색 기록, 기기 또는 기타 ID, 이름, 이메일.

## 3. 보안 관행(Security practices) 답변

| 질문 | 답변 | 근거 |
|---|---|---|
| 전송 중 데이터 암호화 | **예** | 모든 API HTTPS (`api.lingring.site`) |
| 사용자가 데이터 삭제 요청 가능 | **예 (앱 내 제공)** | 계정 탈퇴 = 즉시 hard-delete (`src/domains/auth/api/withdraw.ts`) |
| 데이터 수집이 선택적 | 일부 | 프로필 사진·통화 녹음은 선택 |

## 4. iOS Privacy Manifest ↔ Play 매핑(정합성)

| iOS `NSPrivacyCollectedDataType` | Play 데이터 유형 |
|---|---|
| `...UserID` | 사용자 ID |
| `...AudioData` | 음성 또는 사운드 녹음 |
| `...OtherUserContent` | 사진 (프로필 이미지) |
| `...OtherDataTypes` | 앱 상호작용 (통화·학습 활동) |

양쪽 모두 **Linked=true, Tracking=false, 목적=App Functionality** 로 일치시킨다.

## 5. ⚠️ 제출 전 확인 필요

1. **통화 음성의 제3자 공유 여부 (중요)** — BE 가 분석을 위해 음성을 외부 AI(예: OpenAI/Anthropic) 로 전송하면 Data Safety 에서 **"제3자와 공유됨"** 으로 선언해야 한다. 그런데 개인정보처리방침은 2026-05-17 에 해당 위탁(OpenAI·Anthropic) 조항을 **삭제**한 상태(`docs/legal/README.md`)다. **BE 팀과 실제 처리 흐름을 확인하고 정책·양식·매니페스트 3자를 정합화**해야 한다.
2. **개인정보처리방침 URL 연결** — Play Console 에 제출할 URL 은 Notion 정본(`docs/legal/README.md`)을 사용. 음성 수집을 양식에 선언한다면 방침 본문에도 그 처리 근거가 있어야 정합.
3. **변호사 검토** — 음성 매칭은 미성년자 보호·녹음 동의가 민감 (legal README 권고).

## 6. 갱신 트리거

- FCM 푸시 도입 → "기기 또는 기타 ID"(푸시 토큰) 추가
- Sentry/분석 SDK 도입 → "앱 정보 및 성능"(크래시 로그) 추가, 제3자 공유 재검토
- 결제(IAP) 도입 → "금융 정보" 추가
- 통화 음성의 외부 AI 전송 정책 변경 → §5-1 재검토
